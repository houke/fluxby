# Documentation, translation and web motion review

Reviewed on 7 October 2026 in `codex/app-review-improvements`. The work covers the browser app, landing pages, Help Center, developer documentation and English/Dutch dictionaries. Existing checkout changes are preserved separately from this review's commit.

## Confirmed findings and fixes

| Finding                                                                                                                  | Correction                                                                                                                                                                                                                                                     |
| ------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Settings called bank accounts “Accounts” / “Rekeningen”.                                                                 | Renamed the section to **Bank accounts** / **Bankrekeningen**, including onboarding references and help instructions.                                                                                                                                          |
| Privacy and marketing copy promised financial data could never leave a device.                                           | Explained optional paired-device sync and TypeSafe AI requests, signaling/relay infrastructure, gateway use and provider credits. The local financial database remains local.                                                                                  |
| Backup instructions pointed to CSV import, and developer documentation proposed importing a browser backup into the API. | Documented encrypted backup/restore under Settings → App settings → Data management. Explained that the browser's v3 `tables`/manifest format and the API's flat export format are different; the API importer replaces financial collections across profiles. |
| API examples used browser UUIDs, incorrect response envelopes and a nonexistent missing-profile authentication error.    | Used numeric API profile IDs, actual `success`/`data` responses, bearer authentication behavior, profile selection defaults and the separate API database.                                                                                                     |
| AI documentation used a stale confidence threshold and promised universal graceful fallback and fixed latency.           | Matched the current `0.6` threshold and shared constant; documented helper-specific fallback and explicit request errors, without an unsupported latency guarantee.                                                                                            |
| Account, budget and transaction instructions described outdated workflows.                                               | Matched the inline Add account form and IBAN rules, monthly budgets/rollover, and the current Add transaction workflow. Added the missing manual-entry help section in both languages.                                                                         |
| English help charts contained Dutch category names, and Dutch release notes retained untranslated or hybrid titles.      | Localized chart labels, corrected Dutch release titles and an account error message, and stabilized demonstration transaction amounts across renders.                                                                                                          |
| Monthly help chart bars had percentage heights without a fixed-height parent and rendered invisibly.                     | Gave the chart a fixed-height plotting area with full-height bars scaled from the bottom. Added localized accessible bar labels and a browser regression for visible bars.                                                                                     |
| Progress demonstrations animated width/top, and broad transitions could animate unrelated properties.                    | Used `scaleX` for progress, `translateY` for the dropping file, `scaleY` for chart bars, and explicit transition properties across help demonstrations and shared buttons/cards.                                                                               |
| Hero CSS animations continued offscreen, permanent layer hints persisted, and reduced-motion styles were incomplete.     | Reused visibility/motion activity tracking for the hero, removed unnecessary permanent `will-change`, and added reduced-motion rules in both app and landing CSS while retaining animation completion behavior.                                                |

The motion changes follow browser guidance to avoid layout-triggering animated properties and unnecessary permanent layers: [animation performance](https://web.dev/articles/animations-and-performance) and [animation implementation](https://web.dev/articles/animations-guide).

## Validation

Verification uses the complete current checkout, including its pre-existing changes.

- English/Dutch dictionary shape, runtime references and interpolation placeholder parity are covered by the localization suite. Placeholder parity checking was added during this review.
- Browser documentation checks visit all 17 help routes and 17 developer routes in both languages at 1,440px and 393px: **136 route/layout checks**, with headings visible, no undefined translation output, no horizontal document overflow and no page errors.
- Browser Settings checks verify **Bank accounts** / **Bankrekeningen** and computed reduced-motion styles. Hero checks verify running animation, offscreen pause, stable paused transforms and visible content with reduced motion.
- The existing public accessibility regression covers **40 page/language/theme/width combinations**, including keyboard scrolling of long code samples, with no reported WCAG AA violations.
- Visual inspection includes English desktop and Dutch mobile analytics help pages. The new regression requires all ten monthly chart bars to have a visible plotted height.
- Final checks pass: lint with no warnings/errors, typecheck, **148 test files / 1,797 tests**, **seven Chromium regressions** and the monorepo production build. The first unrestricted parallel unit run hit three timeouts; rerunning the full suite with four workers passed without changing test timeouts. Final browser verification uses dedicated loopback servers for this checkout after the shared development servers were replaced by a separate review snapshot.

Browser checks run against the local Vite servers using disposable Chromium contexts. Native Tauri, physical paired devices and deployed production behavior are outside this review. The CSS changes reduce known layout work; this review does not claim a measured FPS, CPU or memory improvement. Existing Vite large-chunk and Node-adapter externalization warnings remain build diagnostics.

Changes are committed locally; no push or deployment is included.
